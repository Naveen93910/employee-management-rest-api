# Employee Management REST API

## Project Description
This is a Spring Boot CRUD REST API project for managing employee data using MySQL database.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Lombok
- Maven
- PostMan

## Features
- Add Employee
- Get All Employees
- Get Employee By ID
- Update Employee
- Delete Employee
